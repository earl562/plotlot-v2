# Workflow review template

Copy this outline into a new skill only after agreeing on a real example with
Phat and Earl. Replace every bracketed field before marking it usable.

- **User goal:** [What decision or task does this support?]
- **Trigger and scope:** [When should an agent use it?]
- **Inputs and allowed sources:** [Which records, jurisdictions and dates?]
- **Product route:** [How does an agent reach it? See `FEATURE_MAP.md`.]
- **Steps:** [Shortest path through existing PlotLot capabilities.]
- **Evidence required:** [Source URL, record ID, timestamp, parcel identity, conflicts.]
- **Abstain or escalate when:** [Missing facts, disagreement, unsupported source.]
- **Verification:** [One real scenario, one failure scenario, matching test lane.]
- **Output:** [What the reviewer sees and what remains unresolved.]
- **Human signoff:** [Who accepts it before an investment or outreach action?]

For skill changes, preserve a small before/after observation: request, agent
actions, artifacts, rubric result, and reviewer decision. An eval score alone
does not prove that the underlying real estate fact is true.
